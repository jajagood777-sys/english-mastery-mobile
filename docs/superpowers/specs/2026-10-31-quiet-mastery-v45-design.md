# 言道修炼殿 V4.5 Quiet Mastery 视觉与导航设计

## 意图

把 V4.4 的功能完整学习 PWA 提升为适合长期 iPhone 使用的现代东方书院界面。首屏只突出一个真实的今日学习行动，五个顶层入口保持稳定，训练与阅读优先保证输入、选词和数据证据不受视觉改造影响。

## 目标与边界

- 目标：统一日夜主题、字体层级、间距、按钮、卡片和导航；让首页的今日学习 CTA、真实统计和学习路径一眼可懂；改善 375–430px 手机布局、safe-area、焦点和触控反馈。
- 保留：现有路由、每日 JSON、迁移挑战、阅读理解、K/V/N、计时、战报、备份恢复、localStorage、Service Worker 和九张已授权 WebP。
- 不做：数据 schema 迁移、学习流程重写、外部 UI 框架、付费服务、全新账户系统、清空缓存或本地记录。

## 设计系统

- 颜色：暖象牙 `#F5F3ED`、卡片 `#FDFCF8`、正文 `#1E3029`、辅助 `#68766C`、深玉 `#234A3D`、暖金 `#D3BE91`；夜间使用 `#14241E`、`#20342B`、`#F1EDDF`。
- 字体：系统中文字体（PingFang SC / Noto Sans CJK）与系统英文无外部字体下载；标题使用较紧的字距和清楚的层级，阅读正文保持 18–21px 与约 1.85 行距。
- 形状：主 Hero 24px 左右圆角，普通面板 16–20px，1px 边界和轻阴影；只给有层级意义的区域使用容器。
- 图标：在 `index.html` 使用同一笔画宽度的内联 SVG，中文标签保持现有五个入口；无第三方图标包。
- 交互：主 CTA 使用深玉与象牙对比，所有按钮至少 44px 高，焦点使用暖金外框，尊重 `prefers-reduced-motion`。

## 页面结构

移动端：

```
品牌行
今日主 CTA / hero
真实三项统计
今日综合学习路径
低优先级快捷入口与近期进度
安全区内的五栏底部导航
```

桌面端：Hero 与统计/学习路径组成两列，底部导航仍保留但不遮挡内容。

首页由现有真实 `homeSummary`、`dailyPack`、`dailyJourney` 和进度数据驱动，不复制原型的演示数字。训练、阅读、进度和我的沿用现有 DOM 与事件，只统一视觉和间距；阅读区域不放覆盖层，保留原生选词与复制。

## 验收证据

- `npm run check` 与项目 Skills 的数据安全、每日包、移动可访问性、PWA 检查通过。
- Chromium 模拟 375×812、390×844、430×932、768×1024、1280×800：无横向溢出，五栏导航可达，主 CTA、输入、迁移挑战、阅读小测和战报流程保持可用。
- 真实 iPhone Safari、键盘和本地私有数据仍需用户设备验收；本次不触碰真实 storage。
